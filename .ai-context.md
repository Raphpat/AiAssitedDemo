# Project Context

## Project Structure

- Backend: Gradle-based Java Spring Boot project with math utilities (Java 21)
- Frontend: Angular standalone components application

## Project Organization

### Backend

- `src/main/java/com/example/`
  - `MathUtils.java`: Core math operations
  - `MathApplication.java`: Spring Boot application with CORS configuration
  - `MathController.java`: REST endpoints

### Frontend

- `frontend/src/app/`
  - `components/`
    - `calculator/`: Calculator component
    - `prime-checker/`: Prime number checker component
  - `services/`
    - `math.service.ts`: Service for backend API communication

## TypeScript & Angular Standards

- Use strict TypeScript configuration
- Prefer type inference over explicit typing where possible
- Use modern ES features (optional chaining, nullish coalescing, etc.)
- Implement strict null checks
- Use interface segregation for better type organization
- Leverage const assertions and literal types
- Use discriminated unions for complex state management
- Prefer readonly arrays and objects where immutability is desired
- Use template literal types for string manipulation
- Implement proper type guards and type narrowing
- Use private class fields with # prefix where appropriate

## Configuration

- "MathApplication": Launches Spring Boot backend on port 8080
- "Launch Frontend": Starts Angular dev server on port 4200
- "Launch Full Stack": Compound launch for both frontend and backend

- Spring Boot 3.2.3
- Java 21
- Gradle build system

### Frontend Configuration
