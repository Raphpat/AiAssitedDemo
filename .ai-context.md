# AI Assistant Context File

## Project Structure
- Backend: Gradle-based Java project with math utilities
- Frontend: Angular application (in progress)

## Git Branches
- `ai_example_dev`: Initial branch with backend math utilities
- `feat_ai-1`: Frontend implementation branch

- Committed to `ai_example_dev` branch
